# Contributing

Thanks for your interest in improving this template.

## How to contribute

1. Fork the repository
2. Create a branch (`git checkout -b fix/your-fix`)
3. Make your changes
4. Test locally (open `index.html` in a browser)
5. Commit and push
6. Open a Pull Request

## Guidelines

- **No dependencies.** This template is vanilla HTML, CSS, and JavaScript. No frameworks, no build tools, no npm packages.
- **Keep it simple.** Every line of code should serve a clear purpose.
- **Accessibility matters.** Use semantic HTML, ARIA attributes, and keyboard navigation.
- **Bilingual support.** Changes to text content should be applied to both `ru` and `en` versions.
- **Test dark mode.** Verify your changes work in both light and dark themes.

## What we accept

- Bug fixes
- Accessibility improvements
- Performance optimizations
- New case study components (with documentation)
- Translation improvements
- Documentation updates

## What we don't accept

- Adding JavaScript frameworks or libraries
- Adding CSS preprocessors (Sass, Less, etc.)
- Adding build tools (Webpack, Vite, etc.)
- Changes that break the zero-dependency philosophy

## Code style

- 2-space indentation
- CSS custom properties for colors and spacing
- Semantic HTML5 elements
- Comments for non-obvious logic only

## Reporting bugs

Use the [Bug Report](https://github.com/diyoriko/portfolio-template/issues/new?template=bug_report.md) issue template.
